# Local Fonts Directory

Put your **Google Sans / Google Sans Khmer** font files here:

### Supported File Names:
- `GoogleSans-Regular.ttf` or `GoogleSans-Regular.woff2`
- `GoogleSans-Bold.ttf` or `GoogleSans-Bold.woff2`
- `GoogleSans-Medium.ttf` or `GoogleSans-Medium.woff2`
- `GoogleSans.ttf` or `GoogleSans.woff2`
- `GoogleSansKhmer.ttf` or `GoogleSansKhmer.woff2`
- `GoogleSansKhmer-Bold.ttf` or `GoogleSansKhmer-Bold.woff2`

The app is already configured to automatically load any of these font files!
